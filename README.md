# Московские практики by ADNOMADS

Статический сайт на Astro. Локально: `npm run dev`. Сборка: `npm run build`, результат в `dist/`.

Пуш в `main` собирает проект и заливает только `dist/` на REG.RU. Секреты workflow: `FTP_SERVER`, `FTP_USERNAME`, `FTP_PASSWORD`, `REG_PATH`.

Правила работы агентов: `AGENTS.md`.
