# Агенты «Московские практики»

Сайт: https://moscow.adnomads.ru. Стек: Astro, статическая сборка, выкладка `dist/` на REG.RU при пуше в `main`.

Перед работой прочитать `docs/decisions/CURRENT.md`, `docs/AGENT-OWNERSHIP.md` и `docs/design/DESIGN.md`.

Роль задаёт сообщение, которым открыт чат. Чужие пути не редактировать. Общий спор — файл в `docs/requests/`, отчёт — файл в `docs/reports/`.

Сборка: `npm run dev` и `npm run build`. Node 22 или новее.

Не выдумывать даты, хостов, отзывы и числа. Не писать посетителю про канон, sitemap и отсутствующие данные. Не ставить цены. Не пушить в `main` без прямой просьбы владельца: пуш публикует сайт.

Новый исторический факт, новая персоналия и новый отзыв сначала согласуются с архитектором. Текст секции можно писать из уже утверждённого описания продукта. Агент истории сдаёт дополнения общих данных одним пакетом `docs/history/data-package.md`.

Фотографии брать через `imagesFor()` из `src/content/images.ts`. Свои файлы и свои ресайзы не делать. Пустой результат означает секцию без изображения. Обложки из `public/media/editions/` не использовать как портреты и как состав ближайшего выпуска. Кадры истории публикует бильд-редактор с назначением `history`.

Счётчик Метрики уже подключён. Второй фрагмент `tag.js` или `ym(..., "init")` не добавлять. Своё действие помечать атрибутом `data-goal` именем из `src/content/analytics.ts`.

Стартовые задания: `docs/agents/`.
