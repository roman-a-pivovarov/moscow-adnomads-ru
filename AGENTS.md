# Агенты «Московские практики»

Сайт: https://moscow.adnomads.ru. Стек: Astro, статическая сборка, выкладка `dist/` на REG.RU при пуше в `main`.

Перед работой прочитать `docs/decisions/CURRENT.md`, `docs/AGENT-OWNERSHIP.md` и `docs/design/DESIGN.md`.

Роль задаёт сообщение, которым открыт чат. Чужие пути не редактировать. Общий спор — файл в `docs/requests/`, отчёт — файл в `docs/reports/`.

Сборка: `npm run dev` и `npm run build`. Node 22 или новее.

Не выдумывать даты, хостов, отзывы и числа. Не писать посетителю про канон и пробелы. Не ставить цены. Не пушить в `main` без прямой просьбы владельца: пуш публикует сайт.

Стартовые задания: `docs/agents/`.
