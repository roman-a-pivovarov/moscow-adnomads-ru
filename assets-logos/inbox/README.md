# Инбокс логотипов

Сюда кладутся файлы, которые Роман нашёл сам. Скрипт `node scripts/logos/intake-inbox.mjs` переносит их в реестр кандидатов. Принятым основным знаком файл становится после выбора в каталоге.

Имя файла — короткое имя агентства: `rore.png`, `vk.png`, `agima.png`. Это знак для белого фона. Второй вариант того же агентства: `rore--2.png`.

Рядом можно положить заметку с тем же именем и расширением `.txt`. Первая строка — ссылка на страницу, откуда взят знак.

Подошедшие файлы скрипт убирает в `done/`. Файл с непонятным именем остаётся в этой папке.
