# Старт: хосты

Зона: три файла в `src/sections/hosts/`. Списки не смешивать и не переносить в `src/sections/edition/**`.

| Задача | Файл | Данные |
| --- | --- | --- |
| Кто принимал раньше | `PastHosts.astro`, `#past-hosts` | `pastHostEditions()`, только прошедшие выпуски |
| Подтверждённые хосты ближайшего выпуска | `ConfirmedHosts.astro`, `#confirmed-hosts` | `hostsOf(featuredEdition().id)` |
| Приглашение и формат встречи | `HostOffer.astro`, `#hosts` | `hostOffer`, без имён из двух списков выше |

Пустой ближайший список уже описан в `confirmedHosts`: прошлые агентства туда не дописывать. Неполный прошлый список подписывать спокойно, без отсылки к канону или sitemap. Новое агентство и новое историческое имя — запросом архитектору. Заявка не означает включения. Хосты не платят и им не платят.

Кадр, если он нужен, — `imagesFor("hosts")`. Пока его нет, блоки остаются без фотографии.

Готово, когда на 360 «Показать ещё» открывает хвост прошлого списка, ближайший выпуск без подтверждённых встреч не показывает старые имена, а приглашение не смешано с оплатой участия.
