# Старт: хосты

Зона: `src/sections/hosts/**`.

Два разных блока: кто уже принимал и как стать хостом. Не выводить прошлые имена в блоке ближайшего выпуска — его ведёт агент анонса.

Неполные списки так и подписывать. Новые агентства можно звать оставить заявку, без обещания включения. Хосты не платят и им не платят — это уже есть в вопросах.

Готово, когда «Показать ещё» на мобильном открывает хвост списка, а сценарий хоста не смешивается с оплатой участия.
