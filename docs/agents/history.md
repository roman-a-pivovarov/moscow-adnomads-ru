# Старт: история

Зона: `src/sections/history/**`, `src/pages/history/**`, `docs/history/**`.

Основа — досье `docs/history/moscow-history-source-dossier-2026-11-12.md`. Пять прошедших выпусков, один шаблон. Сентябрь 2026 собирается и без фото, и без хостов.

Общие факты не записывать в `src/content/`. Выпуски, организации, участия, люди и отзывы со ссылками на источники сдать одним файлом `docs/history/data-package.md`. Второй справочник внутри страниц не заводить. Пока архитектор пакет не принял, страницы показывают уже лежащие данные.

Фото берёт бильд-редактор. На странице — `imagesFor("history", editionId)`. Свои копии и ресайзы не делать. Чужую обложку под этот выпуск не подписывать. Пока кадра нет, блок без изображения.

Ссылка «Как это было» на главной ведёт на страницу архива. Внешний рассказ подписан «Опубликованный рассказ». `data-goal="interest_history"` не снимать. Тексты Тильды не копировать абзацами. Полароид в общем CSS не править.

Готово, когда открываются `/history/` и все пять slug, сентябрьская страница собирается без фото, а пакет данных один и ещё не размазан по секциям.
