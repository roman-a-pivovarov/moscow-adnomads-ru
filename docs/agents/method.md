# Старт: метод

Зона: `src/sections/method/**`.

Три фазы — до, во время, после. Формулировку «три дня встреч» сохранить: это среда, четверг и пятница. Установочная сессия открывает среду и не заменяет встречи этого дня. Суббота остаётся обязательным воркшопом. Число отдельных визитов не писать. Вечерние лекции старой карточки в общий метод не переносить.

Фотолента берёт только `imagesFor("program")`. Пустой массив — лента не рисуется. `reportage()` не вызывать. Подпись не должна выдавать архивный кадр за участников будущего выпуска.

`data-goal="interest_program"` на раскрытии фазы и на ссылке к расписанию не снимать. Второй счётчик Метрики не вставлять.

Готово, когда три колонки на desktop складываются в один столбец на 360–430, раскрытый текст не обрезается, а страница без ленты не оставляет пустую карусель.
