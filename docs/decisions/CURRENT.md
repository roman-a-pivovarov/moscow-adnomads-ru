Читать перед работой. Новое решение дописывает архитектор. Блоки сюда сами не пишут: спорный вопрос идёт в `docs/requests/`.

2. Главная — один рассказ. Секции и причины объединения описаны в `docs/ARCHITECTURE.md`.

7. Полароид — общий компонент. На мобильном без наложения.
8. Форма не имитирует отправку.
9. Пуш в `main` выкладывает `dist/` на прежний FTP moscow.adnomads.ru.

## 2026-11-12, контракт первой группы

10. Фотобанк — единственный источник новых кадров. Идентификатор `msk-000001` стабилен. Варианты: `thumb` 360, `web` 1400, `hero` 1920, `portrait` 1000; это потолок длинной стороны из `scripts/photobank/config.mjs`. Назначения: `home`, `history`, `program`, `hosts`, `team`, `hero`. Сайт читает только `data/photobank/published.json` через `imagesFor()`. Пока список пуст, секция живёт без картинки. Архивный кадр не становится портретом и не становится составом будущего выпуска.
11. Три списка хостов разведены по файлам: `PastHosts.astro`, `ConfirmedHosts.astro`, `HostOffer.astro`. Блок `#edition` имена хостов не показывает.
12. `https://adnomads.ru/telegram_irina` проверен 12 ноября 2026: страница делает `window.location='https://t.me/IrinaGeneralova'`. `telegram_roman` ведёт на `https://t.me/romanpivovarov`. Адреса переходников не менять. Для участника и хоста основная кнопка — этот Telegram, письмо остаётся вторым. Различие сценариев: подпись кнопки, фраза первого сообщения, тема письма и разные цели Метрики. `https://adnomads.ru/whatsapp_irina` переходником на WhatsApp не является; прямой `wa.me/79251856536` остаётся контактом Ирины и в сценарии заявки не подменяет Telegram.
13. Счётчик Яндекс Метрики прежнего московского сайта — `98574202`. Он подключён один раз в `Layout.astro`. Новый счётчик не создавать. Цели: `lead_participant`, `lead_host`, `lead_participant_email`, `lead_host_email`, `interest_history`, `interest_program`, `interest_photo`.
14. Пробелы из `docs/GAPS.md` на страницу не выносятся. Новый исторический факт, персоналия или отзыв проходит через архитектора.
15. Агент истории ведёт `src/sections/history/**`, `src/pages/history/**` и `docs/history/**` по досье. Общие факты он дополняет одним пакетом `docs/history/data-package.md`. Фото истории публикует бильд-редактор. Страница читает их через `imagesFor("history", editionId)`.
16. Ближайшая программа: три дня встреч, 17–19 февраля 2027. Установочная сессия открывает среду и не заменяет встречи этого дня. 20 февраля — обязательный воркшоп. Число визитов не публикуется, пока программа не собрана. Формулировку «три дня встреч» в методе сохраняем.
17. Источник сентября 2026 найден: S5, `https://adnomads.ru/history/sz0debeso1-53-moskva-rossiya`. Десять хостов приняты в `participations.ts`. Майские SEO этой статьи и февральский список из краткой майской статьи в данные не входят. Май остаётся на подробном репортаже `2026-may-moscow`. Остальной пакет History принимается целиком, когда файл `docs/history/data-package.md` будет сдан.
18. Сайт показывает только `data/photobank/published.json`. Сырьё и прежние файлы в `public/media/` сами по себе на страницу не выходят. `imagesFor` отбирает кадр по назначению, выпуску и человеку. Для истории выпуск обязателен. Нет варианта `hero` — берётся `web` того же отбора.
