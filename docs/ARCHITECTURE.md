# Архитектура «Московские практики by ADNOMADS»

Рабочий сайт: `https://moscow.adnomads.ru`.  
Репозиторий: `roman-a-pivovarov/moscow-adnomads-ru`.  
Название продукта задаётся только в `src/content/brand.ts`.

## Что это за сайт

Постоянный рассказ о московских программах ADNOMADS: подход, люди, хосты, история, отзывы и ближайший выпуск. Это профессиональный обмен между коллегами. Сайт не описывает проект как благотворительный или некоммерческий и не называет участников «второй лигой».

Периодичность «примерно дважды в год» — ориентир текущего проекта. На страницах не утверждается, что так было всю историю.

## Страницы

- `/` — главная.
- `/history/` — обзор пяти прошедших выпусков и ссылка на ближайший.
- `/history/[slug]/` — один шаблон на прошедший выпуск. Нет фото, хостов или внешней страницы — блок просто не рисуется, сборка не останавливается.
- `/sitemap.xml`

Ближайший выпуск не получает архивную страницу, пока не завершён. Он живёт на главной.

## Данные

| Слой | Файл | Что хранит |
| --- | --- | --- |
| Название | `src/content/brand.ts` | Рабочее имя продукта |
| Описание секций | `src/sections/<блок>/copy.ts` | Текст, который принадлежит одному агенту |
| Выпуски | `src/content/editions.ts` | Московский номер, номер ADNOMADS, даты, статус |
| Организации | `src/content/organizations.ts` | Команды |
| Участие | `src/content/participations.ts` | Кто был хостом какого выпуска |
| Люди | `src/content/people.ts` | Команда и авторы отзывов |
| Отзывы | там же | Цитата и источник |
| Медиа | `src/content/media.ts` и `data/photobank/published.json` | Временные обложки архива и уже отобранные кадры фотобанка |
| Контакты | `src/content/contacts.ts` | Почта и переходники ADNOMADS |
| Связки | `src/content/catalog.ts` | Запросы для страниц |

Уникальные участники и число участий не считаются: опубликованного полного списка людей нет. Уникальные хосты и число встреч тоже не выводятся одной цифрой: часть списков неполная, а одно и то же имя в разных написаниях не склеивается.

Прошлые хосты и подтверждённые хосты ближайшего выпуска — разные выборки. У выпуска 17–20 февраля 2027 подтверждённых хостов нет.

## Переключение анонса

Поле `announcement: "featured"` может быть только у одного выпуска. Сборка не выбирает ближайший выпуск сравнением с сегодняшней датой.

Событие, которое меняет главную: редакционный коммит. В нём завершённый выпуск получает `status: "completed"` и `announcement: "none"`, а следующий известный — `announcement: "featured"`. Пуш этого коммита в `main` запускает сборку и выкладку.

Если следующего выпуска с датами нет, `featured` не назначают. Hero показывает приглашение узнать о следующей программе и не придумывает даты.

Если дата `featured` уже прошла, сборка пишет предупреждение в лог и страницу не переключает. Одной проверки даты недостаточно: решение о следующем выпуске принимает редактор.

## Сборка и публикация

Astro, `output: "static"`. Workflow `.github/workflows/deploy-reg.yml` ставит Node 22, выполняет `npm ci` и `npm run build`, заливает только `dist/`. Секреты те же: `FTP_SERVER`, `FTP_USERNAME`, `FTP_PASSWORD`, `REG_PATH`. Каталог FTP не переносился.

Пуш в `main` публикует сайт. Агенты блоков сами не пушат.

Общие стили — `src/styles/`. Локальные стили секции живут в её `.astro` и не правят общий CSS.

Формы с ответом «отправлено» нет: обработчик не подключён. В сценариях участника и хоста первая кнопка ведёт в `https://adnomads.ru/telegram_irina`, письмо остаётся вторым способом.
