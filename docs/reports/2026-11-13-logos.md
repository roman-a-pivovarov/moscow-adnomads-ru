## Как выбрать

```powershell
node scripts/logos/serve.mjs
```

Каталог: http://127.0.0.1:4317/docs/logos/catalog/index.html

Черновик остаётся в браузере. Экспорт JSON сам реестр не меняет. Применение:

```powershell
node scripts/logos/apply-decisions.mjs путь\к\logos-decisions.json
```

Более новое решение в реестре старый экспорт не затирает. Повторный поиск не сбрасывает уже записанный выбор. Приоритет показа пустой, пока его не задаст Роман.

Интерфейс для блоков: `docs/logos/interface.md`. Зона файлов: `docs/requests/2026-11-13-logos-area.md`. Выбранные копии появятся в `assets-logos/selected/` только после применения. В `public/` ничего не кладётся.

- Red Keds: два вектора из HTML redkeds.com. На сайте отдельно описан герб. Какой из файлов знак, по рисунку не назначалось.

- Segmento: имя файла намекает на новую версию, год смены на странице не указан.
- Яндекс: два файла Wikimedia. Второй может быть тем же знаком или более ранним. Дату по рисунку не ставить.
- VK: «2021-present» — подпись файла, не брендбук.
- Mail.Ru Group: период «до 11 октября 2021» взят со страницы источника, не по рисунку.

- RORE: заголовок сайта связывает RoRe Group и «Родную Речь» в одну карточку.
