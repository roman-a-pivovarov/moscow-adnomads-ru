# Заявка на участие: обработчик не готов для московского домена

13 ноября 2026. Форма на страницу не поставлена: успешную отправку показывать нельзя.

Источник механики: `adnomads-org` ревизия `c00ed3e5c83c3a6e8d7a5a3c9ea2c7ab5d4e7932`, файлы `src/components/Contact.astro`, `src/scripts/ui.ts`, `public/api/request.php`, `public/api/lib/request-lib.php`. Секреты не копировались.

Проверено без создания заявки:

- `OPTIONS` и `GET` `https://adnomads.org/api/request.php` с заголовком `Origin: https://moscow.adnomads.ru` возвращают 405 и не отдают `Access-Control-Allow-Origin`. Браузерный `fetch` с московского сайта до этого адреса не дойдёт.
- Запись заявки не содержит поле источника. Домен, с которого пришёл человек, обработчик не сохраняет.
- Разрешённые поездки: kenya, russia, dubai, japan, china, mexico, unsure, future. Отдельного значения для «Московских практик» нет. Ближайшее существующее — `russia`.
- Конфигурация почты и Telegram лежит вне публичного каталога adnomads.org. Учётная запись FTP московского сайта к ней не привязана. Копировать обработчик в `moscow.adnomads.ru` без этой конфигурации означало бы форму, которая не сохраняет заявку.

Рекомендация: на стороне adnomads.org добавить для `https://moscow.adnomads.ru` разрешение CORS на `POST /api/request.php`, принимать поездку `moscow` с подписью «Московские практики» и записывать источник `moscow.adnomads.ru`. Получатели те же, что у действующей формы. После этого московская страница подключает уже подготовленную механику и оставляет рядом Telegram Ирины. Отправка тестовой заявки организаторам не делалась.
