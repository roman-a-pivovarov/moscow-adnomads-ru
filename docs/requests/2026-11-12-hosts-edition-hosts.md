# Пустой список хостов ближайшего выпуска

Закрыто 13 ноября 2026. Секция `#confirmed-hosts` не рисуется, пока у ближайшего выпуска нет хостов. Ссылка «Хосты выпуска» в этот момент скрыта. Фраза «Состав встреч формируется» стоит в блоке выпуска. Когда `hostsOf` ближайшего выпуска станет непустым, секция и ссылка возвращаются из данных.

## Что уже сделано в зоне хостов

Архитектор поставил на главную `src/sections/hosts/ConfirmedHosts.astro` и ссылку подвала на `#confirmed-hosts`. Агент выпуска убрал имена хостов из `Edition.astro`.

В `ConfirmedHosts` выводятся только записи `hostsOf` для выпуска с `announcement: "featured"`. Исторические имена и пустые карточки туда не подставляются. Пока записей нет, остаётся короткий текст: состав встреч формируется, в список попадут только подтверждённые хосты.

Секцию нельзя просто не рисовать: ссылка «Хосты выпуска» в `src/content/navigation.ts` ведёт на `#confirmed-hosts`.

## Что нужно подтвердить

Оставить это короткое объяснение, пока подтверждённых записей нет.

Если секцию нужно скрывать целиком, архитектор убирает ссылку на `#confirmed-hosts` из `src/content/navigation.ts`. Иначе пункт подвала ведёт в пустое место.

## Почему это не правится в чужих файлах

Порядок секций и навигация — зона архитектора. Тексты выпуска — зона анонса. Схему `participations` менять не нужно.

## Что сломается, если сделать иначе

Подстановка прошлых хостов смешает историю и ближайший выпуск. Удаление секции без правки навигации оставит ссылку без цели.
