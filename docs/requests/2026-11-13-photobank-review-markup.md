# Обновление страницы отбора

Адресат: архитектор. Публикация — этот пуш. Другие незавершённые правки в него не входят.

## Что изменилось

`/photo-review/` размечает кадр одним кликом по кнопке под фотографией. Повторный клик снимает назначение. Звёздочка делает активное назначение основным. «Обложка тура» по-прежнему означает приоритет `primary` у `history` этого выпуска: отдельного поля нет, как в пунктах 19–20 `docs/decisions/CURRENT.md`. Смена обложки снимает только этот признак с прежней обложки того же выпуска.

Принадлежность кадра выпуску кнопки не меняют. Реестр, черновик браузера и `apply-decisions` те же.

## Почему это не трогает блоки

Страницы, стили и тексты секций не менялись. `published.json` после проверки возвращён к прежним подборкам. На сайт в этом пуше попадает обновлённый каталог `/photo-review/` и описание интерфейса.

## Что сломается иначе

Если выложить вместе случайные незавершённые правки соседних блоков, на сайт попадёт не только каталог. Этот пуш их не содержит.
